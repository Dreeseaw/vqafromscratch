# Cement + GQA 70/30 Plan

Goal: rerun the Cement champion bridge family with a real `70/30` VQAv2/GQA train mix, without compression and without grounding loss.

Target architecture:

- frozen SigLIP-B/16 VM
- perceiver bridge
- `question_only`
- `question_hidden_attn` / `attnqquery`
- no dynbudget pruning
- LM top trainable slice + LM visual adapters
- no semantic bottleneck
- no grounding loss

Reference:

- Cement full-eval anchor: `0.6163`
- run: [mmcement_v1_20260316_siglip_cement_questiononly_s42](/home/wdree/percy/vqafromscratch/logs/mmcement_v1_20260316_siglip_cement_questiononly_s42)

Mixing rule:

- use a true per-batch `70/30` VQAv2/GQA mix
- implemented via `gqa_train_mix_ratio=0.3`
- no pointing data in this experiment

Runtime stance:

- safer host-memory profile than the old default wrappers
- `batch_size=96`, `grad_accum_steps=2`
- `eval_batch_size=96`
- `num_workers=1`, `prefetch_factor=1`, `--no-pin_memory`

Outputs:

- training run with periodic VQAv2 evals
- posthoc full VQAv2 eval at best periodic step
- posthoc GQA exact-match eval on a `5k` slice at the same best step

Decision rule:

- if VQAv2 full eval improves over Cement, keep GQA mixing alive as a bridge-stage axis
- if VQAv2 is flat/down but GQA exact-match rises, treat this as specialization rather than a mainline win
